# W8 - Foundation: IaC + Kubernetes

## Weekly Goal

Build basic confidence with infrastructure as code and Kubernetes primitives:

- Understand Terraform workflow and HCL syntax.
- Prepare Kubernetes local environment with Docker Desktop, kubectl, and minikube.
- Learn Terraform state, remote backend, locking, and module layout.
- Start a mini Kubernetes platform lab on minikube.
